title: Slack 図解レポート（1枚長尺）ビジュアル仕様
---

## 前提（ユーザー確定分）

- **1枚・縦長**で複数商品を上から下へ。
- **ダーク基調**（ライトテーマは使わない）。
- **フォント**は指定なし → 実装側は **日本語読みやすいゴシック**（`system-ui` + `"Noto Sans JP", sans-serif` フォールバック等）。
- **表の左列だけを設けない**（スプシで整理済みの行だけを並べる）。
- **重複・派生の説明**は図に載せない（`product_queue` 段階で済ませたデータのみ）。

## 1商品ブロック（任せた結果のワイヤー）

各商品は **同じ構造のカード**を縦に積む。

```
┌─────────────────────────────────────────┐
│ [#seq]  （左上バッジ・小さめ角丸）        │
├──────────────────┬──────────────────────┤
│                  │ ブランド（小・淡色）   │
│   商品画像        │ 商品名（大・白）     │
│   固定比率        │ 発売開始日（中）     │
│   （角丸）        │ ASIN `B0...`（等幅） │
│                  │ amazon.co.jp/dp/…   │
└──────────────────┴──────────────────────┘
```

- **#seq**: 通し番号。左上 **バッジ**（背景はアクセント1色、文字は白）。
- **画像**: 左 **幅 38〜42%** 程度、**1:1 または 4:5** にトリミング（実装で `object-fit: cover`）。
- **右列**: 上から **ブランド → 商品名 → 発売日 → ASIN（コピーしやすい表記）→ 短いリンク表記**。
- カード同士は **16〜24px の隙間**＋任意で **1px の区切り線**（低コントラスト）。

## ページ全体

- **最上段**: タイトル行（例: `新着候補レポート`）＋ **JST 日付**（小さめ）。
- **本編**: 上記カードを **最大件数は実装で制限**（長尺が破綻しないよう、例: 12 件まで。超過分は「他 N 件はスプシ参照」1行テキストでよい）。
- **最下段（任意）**: 1行だけ「データ元: product_queue / 未通知のみ」など **運用メモ**（小さく）。

## カラー目安（ダーク）

- 背景: `#0f1419` 前後  
- カード面: `#1a222d`  
- 主文字: `#f2f4f7`  
- 副文字: `#9aa7b2`  
- アクセント（バッジ）: `#3d8bfd` または `#5c7cfa`（実装時に1色に統一）

## Slack への載せ方

- 生成した **PNG の公開 URL**（Artifacts・一時ホスト・既存のデプロイ先）を `image` / `files.upload` で投稿。  
- 詳細は実装フェーズで `notify-product-ready` 拡張または専用スクリプトに記載する。
