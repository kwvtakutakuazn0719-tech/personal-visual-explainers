# 情報源ごとのリスク整理（方針）

「できる／できない」より、次を毎回メモする。

- **安定性**: レイアウト変更で壊れやすいか
- **ログイン壁**: 要ログインか
- **規約**: ToS / robots / API 利用条件
- **レート**: 連続アクセスの制限

## 優先

- 早期スパイクは **Amazon.co.jp** を優先（前提を固める）。
- 公式・系列 EC・ブログは同じ観点で後から足す。

## 禁止の考え方

- 規約違反になりうる自動取得は、**ユーザーが許可した範囲のみ**。
- 不確実な手段をスキル内で拡大しない。
