# Shopee プロダクト名（リスティング・検索向け）

図解 HTML の見出し用タイトルとは **別物** である。  
図解内の商品名はカテゴリスキル Step 1 の **ユーザー入力どおり**（共通スキル禁止事項）。  
本ファイルは **Shopee 出品欄に貼る英語のプロダクト名**（AEO / SEO 寄りの一行）のためのルール正本。

## 目的

検索・関連表示で拾われやすい **1 行の英語タイトル**。図解で使った前提情報（Amazon URL・公式・収集メモ）と **同一の調査結果** から作る。根拠のない誇大表現や無関係キーワードの詰め込みは避ける。

## 構成（左からこの順で意識する）

1. **ブランド名**
2. **具体的商品名**（モデル名・シリーズ名など）
3. **どういう商品か**を短く（例: running shoes, trekking shoes, hiking boots, wristwatch, wireless earbuds, daypack）
4. **Shopee らしく**、当該商品と **一緒に検索されそうな語**を数個（用途・地形・天候・素材・活動など。図解・ソースに現れる語を優先）

区切りは **スペース** または **カンマ＋スペース** でよい。読みやすさと検索語の両立を優先。

## 文字数

- **英語表記 1 行**
- **100 文字以内**（厳守）
- **1 文字 = 1** と数える: ラテン文字 `A` は 1、数字・スペース・カンマ・ハイフンもそれぞれ 1。  
  提出前に **実文字数を数える**。**使用文字数 N/100** は完了報告で **コードフェンスの外**（見出し「プロダクト名」の下の行など）にだけ書く。**コードブロックの中身は商品名の1行のみ**（コピー時に余計な文字が入らないようにする）。

## 禁止・注意

- 図解共通禁止（価格・配送・返品）に加え、**誤認を招く別商品名**は入れない。
- ユーザーが Step 1 で渡した **商品名の意図**（どの SKU／モデルか）と矛盾させない。
- 100 を超える場合は **後ろの共起語から削る**。ブランド＋具体名＋カテゴリ短語は可能な限り残す。

## 図解フロー内のレビュー（SEO / AEO）

**一本化パス**（`shopee-outdoor-explainer` などカテゴリ図解スキルに従う）:

1. **下書き** — 本ファイルのルールで英語1行・100文字以内を作る（**Step 4c**）。  
2. **レビュー** — **`.claude/skills/shopee-product-name-seo-aeo-review/SKILL.md`** と **`.claude/skills/shopee-product-name-seo-aeo-review/references/seo-aeo-rubric.md`** を読み、そのスキルどおりに下書きを点検する（**Step 4d**）。**必須修正**と **改版ヒント**はワークフロー内に留め、**完了報告にレビュー長文を載せない**。  
3. **再作成** — Step 4d で内部確定した **必須修正・改版ヒント**を踏まえ、本ファイルのルールで **最終行**を組み直す（**Step 4e**）。100文字超えないよう再カウント。必須修正を無視しない。

**再レビュー**: 原則 **1 周**（4c→4d→4e）で完了。争点が残る場合のみ、4d〜4e を **最大もう1 周**まで（計2周）。それ以上はユーザー確認。

完了報告に出す **プロダクト名コードブロック**は、常に **Step 4e 確定後の最終行**のみ。

## 完了報告での出力（必須）

- **Shopee 関連の図解 HTML を作ったときは毎回必ず出す。省略しない。**
- 完了報告では、**HTML 2 枚の案内に加えて**、Shopee 商品ページに貼る **最終プロダクト名**を出す。
- 文字数は **`使用文字数 N/100` をコードフェンス外**に書く。
- **コードブロック内は商品名 1 行のみ**にする。説明文・レビュー文・箇条書きを混ぜない。

## 品質のセルフチェック

- [ ] ブランド → 具体名 → カテゴリ短語 → 共起語の流れになっているか
- [ ] 文字数 ≤ 100（再カウント済み）か
- [ ] 図解作成時の調査ソースと整合しているか
- [ ] Step 4d の **必須修正**・**改版ヒント**を反映したか（必須修正が「なし」なら改版のみ／ヒントもなしならスキップ可）
