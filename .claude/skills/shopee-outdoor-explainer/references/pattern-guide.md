# Layout Pattern Guide

商品カードを生成する前に、以下の判断基準でパターンを選ぶ。

---

## Pattern A — Feature Deep-Dive

**ファイル:** `references/pattern-a-feature.html`

### 使う商品タイプ
- 専用設計された単品アイテム（シューズ・ウェア・専用ギア）
- 技術・素材・機能が主な差別化ポイントの商品
- 同一モデル内のバリュエーションが「色・サイズ」のみの商品

### 判断サイン
- ブランド独自テクノロジーが3つ以上ある
- 「何でできているか・どう動くか」を説明する必要がある
- サイズ感・フィット感が重要な商品

### 構成
1. Hero（ブランド・商品名・タグライン・Best-for pills）
2. 商品画像 + 主要機能3つ（詳細説明あり）+ スペック数値バッジ
3. 素材・パーツサマリー（3カラム：アッパー/ミッドソール/アウトソールなど）
4. サイズガイド or フィットノート
5. フッター

### 具体例
- New Balance 860 v14（安定サポートシューズ）
- Salomon Ultra Glide 4（トレランシューズ）
- Arc'teryx Beta AR Jacket（テクニカルアウター）

## Pattern B — Lineup Navigator

**ファイル:** `references/pattern-b-lineup.html`

### 使う商品タイプ
- 同シリーズに複数モデルが存在し、「どれを選ぶか」が買い手の主な疑問
- ギア比・スペック・用途が型番ごとに異なる商品
- バリュエーションが「PG/HG/XG」「S/M/L/XL」以外の意味を持つ商品

### 判断サイン
- 同シリーズに3モデル以上あり、用途が異なる
- 型番を間違えると目的に合わない（選択を間違えると困る）
- スペックよりも「自分に合うモデルはどれか」を知りたいユーザーが多い

### 構成
1. Hero（シリーズ名・カテゴリ・タグライン・Best-for pills）
2. 商品画像 + 共通の主要機能3つ（シリーズ全体に共通するもの）+ 共通スペックバッジ
3. モデル比較表（3〜6モデル：ギア比/スペック/重量/推奨用途）
4. カスタマーレビュー（3件）
5. テクノロジーピル一覧
6. フッター

### 具体例
- Shimano 24 STRADIC SW（リール多番手展開）
- Garmin Fenix 7シリーズ（サイズ・モデル違い）
- Therm-a-Rest NeoAir系（厚み・サイズ違い）

## Pattern C — Activity Guide

**ファイル:** `references/pattern-c-activity.html`

### 使う商品タイプ
- 汎用的なライフスタイル・アパレル・アウトドアギア
- 「自分のアクティビティに合うか」が買い手の主な疑問
- 複数のシーンや用途に使える商品

### 判断サイン
- ターゲットユーザーの幅が広い（初心者〜上級者）
- 「どんな場面で使えるか」をビジュアルで伝えることが有効
- スペックより「どんな人が買うか」の共感が購買を左右する

### 構成
1. Hero（ブランド・商品名・タグライン・Best-for pills）
2. 商品画像 + アクティビティシナリオ3つ（「こんな人に向いている」をアイコン付きで）
3. 機能ハイライト（4カラム・コンパクト）
4. 素材・テクノロジーサマリー
5. フッター

### 具体例
- Columbia Omni-Heat Jacket（タウン〜アウトドア兼用）
- Black Diamond Trail Poles（ハイキング〜ファストパッキング）
- Stanley Quencher Tumbler（日常〜アウトドア兼用）
- テントや寝袋など汎用キャンプギア

---

## 判断フローチャート

```
商品を確認する
  │
  ├─ 同シリーズに複数モデルがあり用途が型番で異なる?
  │    YES → Pattern B（Lineup Navigator）
  │
  ├─ ブランド独自技術が多く「何でできているか」が重要?
  │    YES → Pattern A（Feature Deep-Dive）
  │
  └─ どちらでもない（汎用・ライフスタイル・幅広いユーザー向け）?
       → Pattern C（Activity Guide）
```

迷ったら Pattern A を使う（最も汎用的）。
